# Digital College · Telegram Assistant

Telegram Mini App и голосовой помощник для студентов и преподавателей Digital College.

**Работающее Mini App:** https://digital-college-telegram-74926.dewylion4.chatgpt.site

**Бот:** https://t.me/AccountantBookkeeperBot — отображаемое имя «Digital College · Помощник».

## Возможности

- Расписание 59 групп с учётом даты и недели семестра.
- Выбор группы при первом входе, прелоадер и локальный кэш расписания.
- Быстрое переключение дат без чтения Google Таблиц.
- Задания группы, сроки сдачи, текстовые ответы и ссылки на работы.
- Роли преподавателя и студента, проверяемые на сервере по Telegram ID.
- Голосовые запросы расписания, списка заданий и создания задания.
- Уведомления о приближающихся сроках для подписавшихся пользователей.

Расписание загружено из предоставленного колледжем Excel. В исходнике оно отмечено как проект,
не утверждённый директором; эта отметка сохранена. Если преподаватель для конкретного варианта
не определён однозначно, приложение предлагает уточнить его по исходному расписанию.

## Структура

```text
miniapp/          интерфейс, сервер Cloudflare Worker, расписание и тесты
telegram-bot/    Python-процесс Telegram: голос, команды, напоминания
docs/            инструкции размещения и переноса
Dockerfile       готовый образ для круглосуточного запуска бота
compose.yaml     запуск с постоянным хранилищем и перезапуском
railway.json     параметры сборки сервиса Railway
```

GitHub хранит код. Для постоянной работы Python-бота нужен запущенный сервер или компьютер.
Mini App уже размещён на Sites и не зависит от локального компьютера. Этот репозиторий —
копия его исходников: изменения сайта публикуются отдельно через Sites и не выкладываются
на работающий сайт автоматически от одного GitHub push.

## Локальный запуск

Python 3.11 или новее. В корне проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r telegram-bot/requirements.txt
Copy-Item .env.example .env
# Заполните четыре обязательных значения в .env.
.\.venv\Scripts\python.exe telegram-bot/college_bot.py
```

Обязательные настройки: TELEGRAM_BOT_TOKEN, OPENAI_API_KEY, COLLEGE_APP_URL, BOT_SERVICE_SECRET.
Последний ключ должен совпадать с серверным секретом Mini App. Учётная запись Google и её JSON
нужны серверу Mini App, Python-боту они не требуются. Рабочие ключи и данные пользователей в GitHub
не загружаются. Полный список серверных переменных — в docs/DEPLOY.md.

## Круглосуточный запуск на сервере

С Docker Compose:

```bash
docker compose up -d --build
docker compose logs --tail=100 -f bot
```

В той же папке должен быть локальный файл .env с ключами. SQLite хранится в постоянном томе
`bot_data`. Политика `unless-stopped` позволяет поднимать контейнер после перезапуска сервера.

Один Telegram-токен должен обслуживаться одним процессом polling. Перед запуском серверной
копии остановите старую локальную копию; не запускайте одновременно два экземпляра.

Пошаговый запуск через GitHub → Railway: [docs/DEPLOY.md](docs/DEPLOY.md).

## Разработка Mini App

Node.js 24, сторонние JS-пакеты не требуются:

```bash
cd miniapp
npm run build
npm test
npm run preview
```

Локальный адрес: http://127.0.0.1:4173. Без Telegram включается помеченное демо с локальными
заданиями. В Telegram подписанные данные входа проверяются сервером, задания и ответы хранятся
в Google. Группа в этой презентационной версии выбирается самостоятельно; интеграции с
официальной системой зачисления и электронным журналом оценок пока нет.

## Проверки

```bash
python -m unittest discover -s telegram-bot -v
cd miniapp
npm run build
npm test
```

Проверки JS покрывают авторизацию, фильтрацию недель, 100 переключений дат без запросов,
объединение 50 одновременных чтений, работу локального кэша, ошибки связи и изоляцию ответов студентов.

## Данные и доступ

Тексты ответов студентов, SQLite, логи и рабочие ключи не включены в исходники. В Google используются
листы College_Profiles, College_Tasks, College_Submissions и College_Reminders.
Состав преподавателей задаётся серверной переменной TEACHER_IDS; переключатель интерфейса
«Студент / Преподаватель» не выдаёт прав. Ответы других студентов недоступны студенту.
